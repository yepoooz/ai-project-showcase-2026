01 / Product perspective

一、我对这个产品的理解

核心定位

品牌审美资产的
移动端载体

我更倾向于把 BM App 理解为品牌审美的延伸：它不仅服务于下单，也让用户在低干扰的浏览中感受美式松弛风格、发现喜欢的款式。

探索型用户

我想逛逛新款

没有明确购买目标，浏览上新，寻找穿搭灵感。

关注风格氛围
外部种草用户

我想找到这一件

从小红书、抖音带着截图或模糊描述来找同款。

关注找款与购买
本次分析的切入点

「逛风格」已形成鲜明体验，「找同款」仍有承接断层。
如何保留品牌氛围，同时让外部种草顺畅走向购买？

02 / What works well

二、我认为最优秀的三个产品设计

优先级 1

视觉设计高度克制，品牌审美与产品体验深度统一

现象

常见电商 / 多重运营信息
开屏广告活动 Banner满减优惠会员弹窗猜你喜欢
Brandy Melville / 视觉聚焦让商品图片成为主角

弱营销干扰 · 统一 UI 与摄影风格

用户场景

像翻阅一本 Lookbook，在没有明确购物任务时，沉浸式感受穿搭氛围。

为什么重要

审美氛围是种草核心。减少信息打断与认知负担，保留对风格的感知。

做得好的本质

界面本身，就是品牌表达。剥离无关信息，让注意力回到款式与穿搭，用一致的页面设计传递品牌调性。

价值品牌塑造商品种草激发购买欲
优先级 2

以新品驱动用户回访，构建健康的用户召回逻辑

现象

常见召回方式 / 促销刺激
优惠券限时折扣会员日
Brandy Melville / 新品与收藏让喜欢成为回访理由

新品信息流 + Wishlist 收藏

用户场景

  1. 浏览上新定期发现新款
  2. 收藏种草保存喜欢款式
  3. 再次回访有空回来查看
  4. 加购下单意向转为购买

为什么重要

服装并非高频刚需。过度依赖优惠，容易培养价格敏感，弱化品牌忠诚。

用户回访动力

对品牌粉丝，刷新品也是内容消费：期待新风格，怕错过喜欢的款式。

做得好的本质

把一次心动，留成下一次回访。上新提供持续浏览的理由，收藏承接暂未购买的兴趣，形成更长效的留存路径。

价值沉淀兴趣促进回访承接购买
优先级 3

交易链路轻量化，匹配审美驱动型消费的决策特点

现象

复杂交易规则 / 增加决策负担
捆绑套餐叠加满减复杂优惠券
Brandy Melville / 轻量结算让购买意向顺畅落地

商品、金额、支付入口清晰呈现

用户场景

  1. 款式种草产生购买意向
  2. 加入购物车选定心仪商品
  3. 确认订单核对商品金额
  4. 选择支付继续完成付款

为什么重要

用户已被款式打动，此时需要的是快速完成购买，保持决策的连贯性。

需要避免的干扰

反复凑单、计算优惠容易让用户转向理性比价，消磨原有购买意向。

做得好的本质

让交易复杂度，匹配购买决策。保留必要的商品与支付信息，减少额外规则和转化拦截，让心动自然衔接下单。

价值减少负担保持意向顺畅下单

03 / Opportunities to improve

三、我认为最值得改进的三个产品设计

按优先级排序 / 找得到，判断得清，承接得住

优先级 1 / 商品发现

缺少图搜能力，文本搜索对服饰属性理解不足

现象

入口 / 找款方式单一有截图，却无处上传

当前页面仅见产品名搜索入口

结果 / 描述词召回受阻「碎花」「条纹」无结果

本次截图中的两次搜索均未命中

用户场景

从小红书 / 抖音种草而来，只记得穿搭截图与视觉特征，不知道 Blair Top 等官方名称。

为什么重要

用户已形成购买意向，却停在找不到同款这一步，后续加购与交易难以继续。

问题本质

用户记得样子，搜索需要名字。视觉找款心智与产品名搜索之间存在断层，需补齐图搜与服饰属性检索。

改进方案

  1. 01 图片搜款上传截图，匹配同款 / 相似款
  2. 02 属性标签颜色、图案、面料、版型、袖长
  3. 03 扩展索引名称 + 品类 + 商品属性
  4. 04 同义词库plaid = 格子；floral = 碎花；tee = T 恤
  5. 05 轻量筛选结果页按颜色、版型缩小范围

衡量指标

图搜使用率图搜召回准确率搜索零结果率搜索→详情点击率搜索退出率
优先级 2 / 购买决策

商品详情页无法充分回答
「这件衣服我穿上是什么效果」

现象

已提供 / 基础商品信息有尺寸，也有面料

截图展示衣长 / 裙长、胸围 / 腰围与成分

截图中未见 / 适配参考松紧与弹性仍需猜

未见标准化版型、弹性等级或试穿反馈

用户场景

喜欢模特上身效果，看到尺寸后仍不确定自己穿会不会过短、过紧，犹豫是否下单。

为什么重要

同为59cm衣长，两件毛衣胸围分别为108cm与100cm。用户仍需结合身材判断松量。

问题本质

从「商品尺寸」到「我的上身效果」，还差一步。基础参数已具备，但不足以独立解释版型、弹性和不同身材的适配感受。

改进方案

01 / 补齐适配说明

在折叠模块内说明测量方式、修身 / 宽松版型、弹性等级与试穿参考。

02 / 汇总版型反馈

收货后选择偏小 / 标准 / 偏大，汇总展示；轻量反馈保持页面简洁。

衡量指标

详情→加购转化率尺码说明查看率整体退货率版型相关退货占比
优先级 3 / 需求承接

缺货商品缺少
高意向用户承接机制

现象

购买入口 / 仍可点击加购想买，才发现没货

操作后提示「此商品暂无库存」

后续承接 / 截图中未见没有下一步

未见补货订阅或相似款推荐入口

用户场景

种草后找到喜欢的款式，却无法加购。希望补货时收到通知，不必反复刷新。

为什么重要

明确的购买意向被缺货打断，用户可能离开；品牌也难以量化未成交的需求。

问题本质

商品暂时缺货，不等于需求结束。缺货提示只告知结果，还需要为「现在买不了」提供后续路径。

改进方案

  1. 01 / 补货订阅
    缺货按钮改为提醒入口；支持该色 / 全色，推送或邮件通知。
  2. 02 / 相似款承接
    确定不再补货时，推荐 3–5 件同版型、同风格商品。
  3. 03 / 记录需求
    汇总订阅人数，为补货采购与款式热度判断提供参考。

衡量指标

缺货商品订阅率补货通知打开率提醒→下单转化率缺货详情页退出率

04 / Prioritization

四、优先级逻辑说明

三点优化对应完整的用户购物漏斗，尤其覆盖小红书 / 抖音种草用户从找款、判断适配，到缺货后等待购买的完整路径。

01 / 漏斗前端

能不能找到商品

搜索 & 图搜承接外部种草流量。找不到商品，后续加购、下单都无从谈起，因此优先级最高。

02 / 决策环节

能不能判断适配

商品详情信息承接搜索成功的用户，帮助判断适不适合自己，影响转化与退货，优先级次之。

03 / 交易末端

想买但没货怎么办

缺货承接保留已经形成的购买意向。处在漏斗末端，覆盖部分用户，在本次排序中优先级第三。

本次排序以路径依赖与覆盖范围为主要依据，优先补齐找款能力。实际排期仍需结合搜索失败量、售罄占比、预期收益与实现成本验证。

05 / Final perspective

五、整体结论

保留「逛」的美感，
补齐「买」的确定性。

Brandy Melville App 最成功的地方，是做好了「逛」这个场景。依靠极简视觉、新品驱动回访、轻量化下单链路，把品牌审美转化成沉浸式购物体验，很好地完成品牌种草。

但本次分析认为，产品的重要短板，是对小红书、抖音等外部平台种草溯源流量的承接不足。用户带着博主穿搭截图、模糊款式描述来 App 找同款，图搜与服饰属性关键词检索能力的缺失，让这条路径难以闭环。

下一阶段的核心目标是：在保留极简风格的前提下，补齐交易链路基础能力，让种草用户想找的时候找得到、找到之后能判断适配度、暂时缺货时需求不会直接流失，提升整条购物漏斗的转化效率。
